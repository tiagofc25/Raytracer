# 3. Write tests with Catch2

## Context

We work with TDD, so writing and running a test must be quick and easy. C++ has no test framework built in.

Alternatives: GoogleTest, doctest, or writing our own assertions.

## Decision

We write the tests with Catch2 v3 (pinned to `v3.7.1`), in `tests/<concept>/`. `catch_discover_tests` registers each `TEST_CASE` with CTest, so `make test` runs them all.

Reason: tests are short and easy to read.

## Status

Proposed

## Consequences

- A test is a `TEST_CASE` with `REQUIRE` lines, readable by people new to C++.
- Each `TEST_CASE` shows up on its own in CTest's report.
- Catch2 adds to the build time.
